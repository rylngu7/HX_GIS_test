# 静态 HTML 预览重构计划

## 一、项目现状分析

当前项目是一个 React + TypeScript + Vite 应用，使用：
- **BrowserRouter** 进行路由管理
- **Tailwind CSS** 进行样式开发
- 多个 React 组件

**问题**：当前配置不支持直接双击 `index.html` 预览，因为：
1. BrowserRouter 在 `file://` 协议下无法正常工作
2. 需要通过 HTTP 服务器运行

## 二、重构方案

### 核心修改

1. **路由策略调整**：将 `BrowserRouter` 改为 `HashRouter`，这样可以在 `file://` 协议下正常工作
2. **构建配置优化**：确保资源路径使用相对路径
3. **提供简单的预览脚本**：方便用户快速预览

## 三、具体修改内容

### 1. 修改文件：`src/App.tsx`

**变更**：
- 将 `BrowserRouter` 替换为 `HashRouter`
- 更新导入语句

### 2. 验证文件：`vite.config.ts`

**检查**：
- 当前配置已经有 `base: './'`，这对静态预览很好
- 保持现有配置不变

### 3. 创建文件：`preview.html`（可选）

**目的**：提供一个简单的引导页面，说明如何预览

### 4. 更新文件：`package.json`

**变更**：
- 添加一个 `build:static` 脚本（可选，用于生成特别优化的静态构建）

## 四、使用方式

重构后，用户可以：

1. **构建项目**：`pnpm build`
2. **直接预览**：在文件管理器中双击 `dist/index.html`
3. 或使用简单的本地服务器预览

## 五、注意事项

- 使用 HashRouter 后，URL 会变成 `#/` 形式，但功能完全相同
- 所有资源路径使用相对路径，确保在任何位置都能正常加载
- 保持原有开发流程不变，开发时仍使用 `pnpm dev`

## 六、风险评估

**低风险**：
- 只修改路由方式，不影响业务逻辑
- 保持向后兼容，开发体验不变
