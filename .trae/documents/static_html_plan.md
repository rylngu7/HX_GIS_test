# 静态 HTML 原型转换方案

## 目标

创建专门用于 Refore HTML to Pixso 插件转换的静态 HTML 页面，确保所有弹窗和界面都能正确显示。

## 实现方案

### 1. 创建项目结构

- 在 `/workspace/prototype/` 目录下创建专用文件夹
- 生成单个静态 HTML 文件（或分多个状态页面）

### 2. 静态 HTML 特点

- **无 JavaScript**：完全使用 CSS 控制显示
- **弹窗永久可见**：所有功能弹窗都展开显示
- **完整样式**：内联或内部 CSS，确保样式不丢失
- **界面分块展示**：将不同的功能界面分组展示

### 3. 具体页面结构

**单个综合展示页面**：
- 顶部：主界面（地图、工具箱）
- 左侧：遥感识别类弹窗（按列排列）
- 中间：遥感处理类弹窗（按列排列）
- 底部：其他功能弹窗

### 4. 文件组织

```
/workspace/prototype/
├── index.html          # 主展示页面（综合展示）
└── assets/
    └── styles.css      # 样式文件
```

## 技术要点

1. **样式内联化**：确保所有样式都在 HTML 内部，使用 `<style>` 标签
2. **响应式设计**：保持原有的 UI 比例
3. **完整展示**：所有功能弹窗都可见，包括：
   - 所有遥感识别类功能弹窗
   - 所有遥感处理类功能弹窗（预处理流程、辐射定标、大气校正、几何校正、影像融合、正射校正、影像匀色、影像镶嵌）
   - 投影系统转换、截图等其他功能

## 与现有代码的关系

- 不修改当前 V1.0 版本的任何代码
- 参考当前组件的 UI 样式和布局
- 手动实现静态版本
